# Compose Chat UI 跨端验收清单

> Phase 1–3 编译门禁已覆盖 Android 单测与 JS 编译；以下是发布前人工 UI 验收最低集。必须使用真实网络，不要只验证 mock 数据。

## Android（`ComposeChatSdkDemoPage`）

- [ ] 发送文本后流式输出正常，Tool Call 卡片与文本同一次发送出现
- [ ] 上滑读历史时新消息不抢滚动，出现「回到底部」按钮与未读计数
- [ ] 点击「回到底部」后列表贴底并清空未读
- [ ] 加载更早消息后可视位置不跳动
- [ ] 发送中显示停止按钮，停止后可再次发送
- [ ] 失败时 Composer 与顶部错误条可展示并可清除

## 生产链路验收（每端执行）

- [ ] 真实网络发送与流式渲染正常；断网前排队请求不会丢失
- [ ] 发送中追加第二条消息进入 `state.queuedMessages`，完成后按序发送
- [ ] 断网时发送进入队列并显示排队态；恢复网络后自动按序重发
- [ ] 流失败后已收文本保留，消息带「内容不完整」状态，可手动重试
- [ ] 连续 100 条以上长会话滚动不冻结、贴底/回底/未读行为正常
- [ ] 文本附件、图片附件和自定义卡片在真实接口返回下可渲染
- [ ] 草稿与附件在页面重建、会话切换后仍保留在 `ChatController`
- [ ] 消息气泡、发送/停止按钮、错误横幅可被屏幕阅读器朗读，核心操作有可聚焦控件

## Android（`ComposeChatSdkDemoPage`）

- [ ] 真机或 emulator 开飞行模式/关飞行模式验证排队与恢复
- [ ] 多行输入按输入框实际宽度换行，新增字符不引起高度跳变
- [ ] TalkBack 逐条读取用户/助手气泡、发送、停止和错误提示

## iOS

- [ ] iPhone 真机或模拟器开飞行模式/关飞行模式验证排队与恢复
- [ ] Dynamic Type 放大后 Composer、气泡和错误横幅不遮挡
- [ ] VoiceOver 逐条读取消息和核心操作

## 鸿蒙

- [ ] 真机或 emulator 开飞行模式/关飞行模式验证排队与恢复
- [ ] 多行输入按输入框实际宽度换行，底部键盘和安全区不遮挡 Composer
- [ ] 无障碍焦点可到达消息、发送/停止和错误提示

## 主题

- [ ] `ChatTheme` token 覆盖背景、气泡、Composer、错误色
- [ ] `ChatStrings` 文案可替换，排队/内容不完整/断线恢复提示不硬编码

## 备注

- 真实生产 AG-UI 网络联调不在 Phase 1–3 范围；使用 `ScriptedSseLlmTransport` + `AgUiLlmProvider` 完成端到端验收。
- IME `Send` action 依赖 Kuikly Compose 键盘 API，当前以点击发送按钮为主路径。
